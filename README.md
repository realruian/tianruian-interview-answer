# AI 漫剧岗位面试回答法

> **把做过的事、想明白的判断，讲成面试官听得懂、愿意继续追问的回答。**

**My Interview Answer** 是田睿安整理的中文面试回答 Skill。它从 AI 漫剧岗位的面试准备出发，把多年面试中反复打磨的表达方式，变成一份可以直接调用的 `SKILL.md`：给出问题和真实材料，生成能开口练习的逐字稿。

`接住问题 → 先给判断 → 分点讲透 → 用例子和做法撑住 → 收回到岗位`

## 这套方法从哪里来

这些年，我在阿里、京东、美团任职过，也曾拿到国内几乎所有主流互联网大厂的 Offer，其中包括百万年薪级别的 Offer。经历过足够多轮面试之后，我越来越确信：一段经历能不能被听见，取决于你能否在短时间里讲清楚自己的判断、行动和取舍。

准备 AI 漫剧岗位时，这件事尤其明显。面试官可能从一个很宽的问题切入：“你怎么用 AI 提效整个工作流程？”“做这种类型的剧，你们在意什么？”回答既要有内容判断，又要落到制作流程、具体做法和岗位价值；现场还得像正常交流，不能像背一篇文章。

于是我把自己的回答习惯拆成了一套可复用的结构，做成这个 Skill，分享给也在准备 AI 漫剧、AI 视频和内容岗位面试的同学。

**我的经历是这套方法的来源；你使用 Skill 时，回答里的个人经历只会取自你自己提供的材料。**

## 它怎样组织一个回答

| 面试现场要解决的事 | Skill 的处理方式 |
| --- | --- |
| 问题很宽，一开口不知道从哪讲 | 先接住题意，再报结论或说明要讲的几点 |
| 观点听起来正确，但没有说服力 | 每一点都接例子、具体动作、工具选择或原因 |
| 讲了很多，却没回答岗位为什么需要你 | 结尾收回核心判断，落到自己能做什么 |
| 文字漂亮，现场念不出来 | 写成有自然停顿和转接的中文口语逐字稿 |
| 题目涉及经历、数据或薪资 | 只使用你这次提供的事实，缺的地方标出 `【待补：……】` |

它覆盖自我介绍、流程题、解决问题题、观点题、成本产能题、开放方案题、事实题、个人情况题和反问。题型不同，回答的骨架也会跟着变：流程题按步骤讲，观点题先判断再解释，数字题先说口径和影响因素。

## 看一个 AI 漫剧面试场景

**面试官问：**“那也想问，你们在做这种类型的剧的时候，在意的点是什么呢？”

**回答片段示意：**

> 您说的是 AI 漫剧这类内容，对吧？我会先看三件事。第一是故事能不能抓住人，开头要让观众迅速明白人物想要什么、阻碍是什么。第二是人物和情绪能不能立住，反转要由人物的选择推出来。第三是呈现能不能把故事讲清楚，比如分镜是否连贯、角色形象是否稳定、配音和节奏有没有把情绪送到位。所以我会先把内容判断做好，再看制作环节怎么保证它最终呈现出来。

这段回答的重点，是把“故事好、画面好”展开成可讨论的判断和检查动作。真正面试时，还要接上**你自己做过的项目、遇到的问题和处理结果**。那部分需要你提供，Skill 不会替你编。

## 适合拿来练什么

- **内容判断：**做 AI 漫剧最看重什么？如何判断一个故事能不能做成剧？
- **制作流程：**从剧本到成片怎么推进？哪些环节适合 AI，哪些需要人工把关？
- **效率与成本：**怎样用 AI 提效整个流程？交付时间和产能受什么影响？
- **问题处理：**角色不一致、镜头不连贯、情绪不到位时怎么办？
- **个人匹配：**为什么做 AI 漫剧？你过去的经历能带来什么？

这些问题是练习入口，不是固定答案库。你可以给它任何一道面试题；题目越具体，提供的真实材料越充分，回答就越能贴近你本人。

## 直接使用

在支持 Agent Skills 的工具里安装后，输入：

```text
使用 my-interview-answer，回答这道 AI 漫剧岗位面试题：
“你是如何使用 AI 去提效整个工作流程的？”
请写成 1～2 分钟能说完的中文逐字稿。
```

如果题目要讲你的工作成果，建议把材料一并给出：

```text
使用 my-interview-answer，回答：
“你做 AI 漫剧时遇到过什么难题？怎么解决的？”

岗位：……
我实际做过的项目：……
我负责的部分：……
遇到的问题：……
我采取的动作：……
可核对的结果：……

只使用以上事实，缺少关键信息就标出待补。
```

你也可以一次给多道题。Skill 会逐题生成回答，方便你朗读、删改和追问练习。

## 安装到自己的 AI 工具

### Codex、Cursor、Copilot CLI、Kimi Code、Gemini CLI

这些工具支持用户级共用目录 `~/.agents/skills/`。macOS / Linux：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/realruian/my-interview-answer.git ~/.agents/skills/my-interview-answer
```

也可以下载本仓库 ZIP，解压后把整个文件夹放到 `~/.agents/skills/my-interview-answer/`。确认目录内直接有 `SKILL.md`。

### Claude Code

如果已按上一步安装，可以链接同一份 Skill：

```bash
mkdir -p ~/.claude/skills
ln -s ~/.agents/skills/my-interview-answer ~/.claude/skills/my-interview-answer
```

也可以直接将文件夹放到 `~/.claude/skills/my-interview-answer/`。其他支持 Agent Skills 的工具，请查看其个人 Skill 目录；网页端和云端产品通常需要在产品内单独导入。

安装后，在工具的 Skill 列表确认 `my-interview-answer` 已出现。已有会话未显示时，可刷新列表或开启新会话。

## 使用时记住一件事

**结构可以借，经历要用自己的。**

这份 Skill 会帮你把回答组织成“能说”的样子，但它不知道你做过哪个项目、拿到了什么结果。看到 `【待补：……】`，请用自己的真实信息补齐；涉及行业数据、平台规则或外部依据，也要核对当下的来源。

它的目标，是让你在面试现场讲得更清楚、更具体、更像一次真正的交流。
